Quizzes

This is the widget that replaces the view block on trlibrary.com/quiz. Every quiz, in an order that is the same for everyone today and different tomorrow, with search and filters. Cards link to the Drupal node for each quiz.

Embed code

<div data-trpl-quiz-gallery></div>
<script src="https://quiz.labs.trlibrary.com/assets/js/gallery.js" async></script>

Paste into a Custom Block or any field using the Full HTML format. Optional attributes: data-limit="3" to show a few, data-topic="Conservation" to preset a filter, data-node-base to point the links somewhere else.
